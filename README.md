## 🚀 Getting Started

Follow these steps to set up and run the project locally on your machine.

### Prerequisites

Ensure you have the following software installed:
- **Node.js** (v18 or higher recommended)
- **npm** (bundled with Node.js)

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   cd KuzwaTeam
   ```

2. **Install project dependencies:**
   ```bash
   npm install
   ```

3. **Launch the local development server:**
   ```bash
   npm run dev
   ```
   Open the address provided in your terminal (typically `http://localhost:5173`) to view the application.

---

## 📦 Production & Deployment

To generate a fully optimized build tailored for production environments:

```bash
npm run build
```

To preview and test the production build locally before deploying:

```bash
npm run preview
```

The application is fully configured for automated integration and hosting via **GitHub Pages**.
